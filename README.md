# 🛣️ Highway WorkD - Secretary View (แอปสืบค้นข้อมูล พรบ. แขวงฯปัตตานี)

ระบบเว็บแอปพลิเคชัน (PWA) แบบอ่านข้อมูลอย่างเดียว (Read-Only) ที่ออกแบบมาเพื่อการสืบค้นข้อมูลโครงการก่อสร้างของแขวงทางหลวงโดยเฉพาะ เน้นความรวดเร็ว สวยงาม และใช้งานง่าย เหมาะสำหรับผู้บริหาร เลขานุการ หรือเจ้าหน้าที่ที่ต้องการดูข้อมูลรายชื่อคณะกรรมการตรวจรับพัสดุโดยไม่ต้องกังวลเรื่องการเผลอแก้ไขข้อมูล

## ✨ ฟีเจอร์เด่น (Key Features)

*   🔍 **Instant Search (ค้นหาทันใจ):** ช่องค้นหาขนาดใหญ่ พิมพ์เลขที่สัญญา (ปน.) ชื่อโครงการ หรือชื่อผู้รับจ้าง ระบบจะกรองการ์ดให้ทันที
*   🎨 **Pastel & Responsive UI:** เลย์เอาต์การ์ดสีพาสเทล 6 โทนสีสวยงามสบายตา พร้อมระบบ Responsive ปรับขนาดและจำนวนคอลัมน์อัตโนมัติ (รองรับตั้งแต่มือถือ แท็บเล็ต ไปจนถึงจอคอมพิวเตอร์ขนาดใหญ่)
*   👑 **Committee Focus:** แตะที่การ์ดเพื่อเปิดดู "รายชื่อคณะกรรมการ" ได้ทันที พร้อมระบบไฮไลต์มงกุฎ (👑) ให้กับตำแหน่ง **ประธานคณะกรรมการ**
*   🛡️ **Safe Read-Only Mode:** ปลอดภัย 100% ตัดปุ่มเพิ่ม/แก้ไข/ลบออกทั้งหมด ป้องกันความผิดพลาดจากการใช้งาน
*   📱 **PWA Ready (ติดตั้งลงมือถือได้):** รองรับการทำ Add to Home Screen เพื่อใช้งานเสมือนแอปพลิเคชัน Native บนสมาร์ทโฟน
*   ☁️ **Supabase Integration:** เชื่อมต่อกับฐานข้อมูลหลักของ Highway WorkD บน Cloud ดึงข้อมูลอัปเดตล่าสุดได้เพียงปุ่มเดียว

## 📂 โครงสร้างไฟล์ (File Structure)

เพื่อให้ระบบทำงานได้สมบูรณ์แบบและรองรับการเป็นแอป PWA ต้องมีไฟล์ดังนี้:

*   `index.html` - ไฟล์หลักที่แสดงผลหน้าจอ
*   `manifest.json` - ไฟล์ตั้งค่า PWA (ชื่อแอป, สีธีม, ไอคอน)
*   `sw.js` - Service Worker สำหรับจัดการระบบแคชและออฟไลน์
*   `icon-192.png` / `icon-512.png` - โลโก้แอปพลิเคชัน
